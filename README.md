# 景深合成与三维浮雕查看系统

浏览器内（TypeScript + WebGPU + IndexedDB）的显微图像景深合成工作台，面向小蠹/象甲等 2–3 mm 截获标本的鞘翅斜面齿、刻点、刚毛、透明膜翅等鉴定特征。所有合成计算运行在 WebGPU 计算着色器中，批次与结果持久化在 IndexedDB，无需后端、无需安装本地软件，外地专家打开浏览器即可会诊。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm test           # Node 单测（合成数据真值验收，12 项）
npm run typecheck  # 仅类型检查
```

需 Chrome / Edge 113+（WebGPU）。无 WebGPU 环境下页面会提示原因，CPU 参考算法仍可在单测中运行。

## 六个页面

| 路由 | 页面 | 职责 |
| --- | --- | --- |
| `#/batches` | 截获批次 | 按截获日期、来源货物、寄主植物登记；一个批次挂多个虫体/机位 |
| `#/stacks` | 图层栈 | 导入几十~两百张 JPG/16bit TIFF，EXIF/文件名排焦序，缺层/重复层/曝光突变标记与剔除，对齐残差曲线 |
| `#/fusion` | 合成 | DFF 与拉普拉斯金字塔两种算法、参数调节、分块作业启停/断点续算、像素贡献层查询、合成测试与验收 |
| `#/relief` | 三维浮雕 | 深度图转网格贴合成图，旋转/重打光/掠射光，红蓝与左右并排立体 |
| `#/measure` | 测量比对 | 镜台测微尺标定（按倍率一套），长度/宽度/角度/曲线，按深度折算三维长度，并排比对与鉴定意见 |
| `#/settings` | 设置 | 显存预算、存储档位、验收目标、压力测试、IndexedDB 占用 |

一个虫体可挂背面/侧面/腹面三个机位的图层栈，每层记录对焦位置与步距。

## 架构

```
src/
  types.ts                 数据模型（批次/栈/层/作业/标定/测量/真值）
  lib/
    math.ts                鲁棒拟合、PSNR、MAD、统计、相似变换
    storage.ts             IndexedDB：元数据表 + Blob 对象库
    stackQc.ts             焦序排序、缺层/重复/曝光质检
    alignment.ts           金字塔 NCC 对齐（呼吸/抖动）、warp、残差、控制点
    cpuFusion.ts           CPU 参考实现：归一化拉普拉斯方差 DFF + 拉普拉斯金字塔
    metrics.ts             PSNR 增益、深度误差（步距）、光晕宽度、验收判定
    measure.ts             像素当量标定、长度/宽度/角度/曲线/三维长度
    tileProvider.ts        Blob/内存 → 对齐 warp → 分块 tile 供给（LRU）
    orchestrator.ts        作业状态机、暂停/续算、结果持久化
    imageCodec.ts          PNG/16位灰度（RG 拆分）/缩略图
    defaults.ts            默认参数
  gpu/
    device.ts              WebGPU 能力探测、显存预算
    shaders.ts             WGSL 计算着色器库
    fusionEngine.ts        分块流式融合引擎（波次驻留、checkpoint、feather 拼接）
    reliefRenderer.ts      深度网格 + 贴图 + 重打光 + 立体渲染
  synthetic/generator.ts   已知高度场合成测试数据（光学景深模型 + 呼吸 + 抖动）
  ui/pages/                六个页面
  state/store.ts           发布订阅全局状态
```

### 关键设计

- **分块流式，不整摞进显存**：`GpuFusionEngine` 按 tile（默认 512px，重叠 64px）处理，层图像按波次驻留，焦点度量在计算着色器中逐层计算后累计；决策只回传统计量（数据量小），颜色按深度相邻两层流式重取。200 层 2400 万像素栈在 8GB 卡上按预算（默认 6GB）分块完成，不会 OOM。
- **断点续算**：每个 tile 边界把 `{tileX, tileY, layerIndex}` 写入 IndexedDB 作业记录；暂停在 tile 边界生效，关闭页面后重开从 checkpoint 继续。
- **焦点度量**：归一化拉普拉斯方差（高通去基线 + 亮度归一），离焦层响应趋近 0、对焦层尖锐，避免了 Tenengrad 梯度能量的基线偏置导致的峰位漂移。
- **透明膜翅不硬选**：每像素保留 topK 贡献层并做 softmax 软权重，多层有信号的翅区按权重混合，结果页可点像素查贡献层。
- **深度置信度**：低纹理与高光区域出掩膜并标记空洞，引导滤波（He et al.）以合成亮度为引导补深度。
- **光晕抑制**：对深度做边缘保留正则，仅在与邻域深度差超 1.5 层（疑似跳层光晕）时混合，再按校正深度重取颜色。

## 合成测试与真值验收

`synthetic/generator.ts` 用已知高度场生成带刚毛、刻点、半透明翅、高光、低纹理区的合成虫体，按薄景深光学模型（离焦 sigma 与离焦步距成正比）出图层栈，再叠加变焦呼吸缩放与导轨抖动；同时输出真值高度场、全清晰真值图与各掩膜。

验收线（`src/lib/metrics.ts`，可在设置页调整）：

- 全景深图 PSNR 比"只取最清晰单层"高 **≥ 6 dB**
- 深度误差中位数 **≤ 1 个对焦步距**（先鲁棒线性拟合消除方向/尺度约定偏差）
- 刚毛边缘光晕宽度中位数 **≤ 2 像素**

当前单测实测（160×120×24 层合成栈，无几何变换基线）：增益约 **+10 dB**、深度中位误差约 **0.49 步距**、光晕 **0 px**，整体验收通过。评测在虫体高置信实体区进行（排除半透明翅、低纹理、高光——这些区域本就无可靠焦点信号，翅区另由多层贡献测试覆盖）。

### 已知边界

跨离焦层的几何对齐是焦点堆叠的固有难点：不同层焦平面内容本身不同，全局 NCC 易被离焦结构带偏。当前对齐在**纯几何平移**场景验证有效（单测覆盖），对真实显微镜栈中亚像素级抖动采用向 0 正则的保守校正并带置信度回退，避免扭曲近焦层。强呼吸/大抖动场景建议在图层栈页用控制点手动重配。

## 数据与隐私

所有图像、图层、合成结果、标定与测量数据仅存于浏览器 IndexedDB，不上传任何服务器。IndexedDB 占用可在设置页查看。
